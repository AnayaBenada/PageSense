Install on your Mac

About 10 minutes, mostly waiting for downloads. You'll do it once.

Open Terminal

Press ⌘ Space, type Terminal, and press Return.

Paste this and press Return

curl -fsSL https://raw.githubusercontent.com/AnayaBenada/PageSense/main/install.sh | bash

This downloads PageSense and the AI models it needs (about 3 GB) and starts PageSense in the background. It starts by itself whenever you log in, so you won't need Terminal again. It's done when it says "Last step: add the extension to Chrome" and opens a folder called extension.

Add the extension to Chrome

  1. In Chrome, go to chrome://extensions
  2. Turn on Developer mode (top right corner)
  3. Click Load unpacked and choose the extension folder that just opened (it's in PageSense in your home folder)

Try it

Click the puzzle-piece icon in Chrome's toolbar and pin PageSense. Open any article or documentation page, press ⌥ Option ⇧ Shift P, and ask a question.

What it does

Built for long pages you'd rather not read top to bottom.

Answers from the page

Ask in plain words. Every answer cites the passages it came from; click one to jump to it on the page.

Smart Find

Like ⌘ F, but by meaning. Search "how do I cancel" and it highlights "end your plan". Press ⌥ ⇧ F.

Reading library

Save pages with ☆, then search everything you've saved by meaning and reopen the page with the passage highlighted.

Private by design

The AI runs on your own computer. Pages, questions and your library never leave it, and there's no account.

Questions

Is it really private?

Yes. The language model (Meta's LLaMA 3.2, run by Ollama) and the search models run on your Mac. The extension only talks to a program on your own computer (localhost). Your saved library is a file in ~/.pagesense.

Why does Chrome need "Developer mode"?

PageSense isn't in the Chrome Web Store yet, and Chrome only lets you add extensions from outside the store with Developer mode on. It's safe to leave on.

The panel says it can't reach the backend

Run the install command again. It restarts PageSense without downloading everything again. If it still fails, the log is in ~/.pagesense/logs/backend.log.

Answers are slow on my Mac

Use the smaller model by running the installer like this: curl -fsSL https://raw.githubusercontent.com/AnayaBenada/PageSense/main/install.sh | PAGESENSE_LLM_MODEL=llama3.2:1b bash

How do I update?

Run the same install command. Updates take about 20 seconds and keep your library. Then click the reload arrow on PageSense in chrome://extensions.

How do I uninstall?

In Terminal, run ~/PageSense/uninstall.sh (add --all to also delete your library), then remove the extension in chrome://extensions. To remove the Ollama app, drag it from Applications to the Trash.

Does it work on Windows or Linux?

The same command works on Linux. Windows isn't supported yet.
